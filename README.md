# Academia de Ensino - Comunidade Vitral

Portal web que agrega as trilhas de formação existentes da Comunidade Vitral em uma interface organizada e acessível.

## Visão

Este portal é projetado para ser:
- **Simples**: Navegação intuitiva, sem barreiras técnicas
- **MissionAL**: Cada trilha aponta para o conhecimento de Jesus, crescimento em caráter e serviço ao próximo
- **Acolhedor**: Linguagem convidativa, acessível a todos

## Estrutura do Projeto

- `index.html` - Página principal do portal
- `/prototype` - Protótipo inicial (para referência)

## Como Executar

Como este é um site estático de HTML/CSS, você pode:

1. **Abrir diretamente no navegador**: Dê duplo-clique no arquivo `index.html` ou abra-o em qualquer navegador moderno.

2. **Servir via HTTP local** (recomendado para melhor experiência):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Então acesse: http://localhost:8000
   ```
