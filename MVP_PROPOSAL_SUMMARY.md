# Proposta MVP: Academia de Ensino da Comunidade Vitral
## Resumo Executivo

Este documento resume a proposta de MVP (Produto Mínimo Viável) para uma academia de ensino que agrege os recursos formativos existentes da Comunidade Vitral em um portal web organizado e acessível.

## Principais Decisões Tomadas

### 1. Valor Central e Público-Alvo
- **Valor Central**: Formação integral de discípulos, com foco inicial em jovens e novos crentes
- **Público-Alvo**: Comunidade como um todo, com ênfase em jovens adultos

### 2. Conteúdo do MVP
O MVP incluirá os seguintes recursos existentes:
- **Trilha de Novos** (9 passos para novos crentes)
- **Trilha Praticando o Caminho** (17 passos em 2 etapas)
- **Trilha de Liderança** (4 módulos de desenvolvimento)
- **Dashboard de Estaçõe** (interface integrada de navegação entre trilhas)
- **Panorama Bíblico** (série de vídeos com visão geral das Escrituras)

### 3. Abordagem Técnica e Experiência do Usuário
- **Plataforma**: Site web responsivo (acessível em desktop e mobile)
- **Abordagem**: Adaptar e conectar os sites existentes (criar um portal que linka para o conteúdo nos repositórios fonte)
- **Identidade Visual**: Usar a identidade visual existente da Comunidade Vitral
- **Experiência**: Navegação organizada por trilhas/módulos com descrições claras
- **Acesso**: Livre, sem login ou rastreamento de progresso no MVP inicial
- **Manutenção**: Sistema híbrido (estrutura no portal, conteúdo nos repositórios fonte)

### 4. Funcionalidades Essenciais
- Navegação clara e organizada pelas diferentes trilhas de formação
- Descrições detalhadas de cada trilha (objetivo, público-alvo, estrutura)
- Links diretos para o conteúdo original nos repositórios fonte
- Layout responsivo para uso em qualquer dispositivo
- Uso da identidade visual estabelecida da Comunidade Vitral

### 5. O que NÃO está incluído no MVP
- Sistema de autenticação ou login de usuários
- Rastreamento de progresso individual ou certificados
- Funcionalidade de busca por tópicos ou palavras-chave
- Áreas de discussão ou comentários entre usuários
- Criação de novo conteúdo (apenas agregação do existente)

## Próximos Sugeridos

1. **Validação do Conceito**: Compartilhar este proposta com líderes da comunidade para feedback
2. **Planejamento de Implementação**: Definir cronograma, recursos necessários e plano de lançamento
3. **Desenvolvimento do Portal**: Criar o site web baseado nas especificações
4. **Teste com Usuários**: Validar com um grupo pequeno da comunidade antes do lançamento geral
5. **Lançamento e Adoção**: Disponibilizar para toda a comunidade e coletar feedback para melhorias

## Conclusão

Esta proposta de MVP fornece uma base sólida para criar uma academia de ensino que agregue valor à Comunidade Vitral tornando mais acessível e organizado o conteúdo formativo já existente. Ao focar na integração do conteúdo existente plutôt que na criação de novo conteúdo do zero, podemos lançar rapidamente uma solução que atenda às necessidades imediatas da comunidade, estabelecendo uma base para crescimento e melhorias contínuas.
